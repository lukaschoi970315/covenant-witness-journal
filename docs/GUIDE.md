# 📱 기록 가이드

[🏠 처음으로](../README.md)

## 1. 휴대폰 · 웹에서 기록하기 (가장 쉬움)

1. 휴대폰 브라우저(또는 PC)에서 이 저장소 첫 화면을 엽니다. (GitHub에 로그인된 상태)
2. 맨 위 **「✏️ 오늘의 기록 쓰기」** 를 누르면 오늘 페이지 편집 화면이 바로 열립니다.
3. 🌅 아침 / ☀️ 낮 / 🌙 밤에 각각 빈칸을 채웁니다. (하루에 여러 번 나눠서 수정해도 됩니다)
4. 오른쪽 위 **Commit changes** → 다시 **Commit changes** 를 누르면 저장됩니다.
5. 1~2분 뒤 증인 기록 모음과 대시보드가 자동으로 정리됩니다.

> 💡 GitHub 모바일 앱은 파일 편집이 제한적이므로 **휴대폰 브라우저(크롬 · 사파리)** 사용을 권장합니다. 홈 화면에 바로가기를 추가해 두면 편합니다.

### 주일 강단 말씀 · 포럼 정리
- 첫 화면의 **「⛪ 이번 주 강단 말씀 · 포럼 쓰기」** 를 누르세요. (`records/연/월/주일날짜-week.md`)
- 주일 1부 · 2부 · 오후 말씀, 참여한 포럼, 주중 말씀, 토요일 밤 주간 결산을 한 페이지에 정리합니다.

### 이달 · 올해의 언약
- `records/2026/11/README.md` (매달), `records/2026/README.md` (매년) 를 열어 연필(✏️) 아이콘으로 수정합니다.

## 2. 기록 표시 (`표시::`)

한 줄에 하나씩, 표시 뒤에 내용을 적으면 자동으로 모아집니다. 같은 표시를 여러 줄 써도 됩니다.

```
- 언약:: 행 1:8 성령이 임하시면 권능을 받고 내 증인이 되리라
- 만남:: 카페에서 오랜 친구 J를 만나 복음을 나눔
- 작품:: 오늘 받은 말씀을 팀원들과 나누는 포럼을 엶
- 성취:: 아침에 붙잡은 '권능'을 어려운 회의에서 체험
- 응답:: (11/10 기도) 어머니 건강검진 결과 이상 없음
- 전도:: 동료 K가 주일 예배에 오겠다고 약속
```

- `<!-- ... -->` 로 감싼 안내 문구는 화면에 보이지 않고 모음에도 들어가지 않습니다. 지워도 됩니다.
- 표시 뒤가 비어 있으면 모으지 않습니다.

> ⚠️ **공개 저장소**입니다. 전도 대상자 · 가족 · 동료의 실명이나 개인정보는 **이니셜(K, P님 등)** 로 적어 주세요.

## 3. 페이지가 없을 때

- 오늘 페이지는 매일 새벽 자동으로 만들어집니다.
- 바로 만들고 싶으면: 저장소 **Actions** 탭 → **🌅 오늘의 기록 페이지 만들기** → **Run workflow**.
- 지난 날짜를 직접 만들려면: **Add file → Create new file** → 이름에 `records/2026/11/2026-11-21.md` 입력 → [templates/daily.md](../templates/daily.md) 내용을 복사해 붙여넣기.

## 4. 사진 · 설교 노트 올리기

1. 해당 월 폴더(예: `records/2026/11/`)에서 **Add file → Upload files** 로 사진을 올립니다. (`images/` 폴더를 만들어 두면 깔끔합니다)
2. 기록에 `![설교노트](images/사진이름.jpg)` 처럼 넣으면 화면에 사진이 보입니다.

## 5. 컴퓨터에서 (git 사용)

```bash
git clone https://github.com/lukaschoi970315/covenant-witness-journal.git
cd covenant-witness-journal

git pull                                   # 자동 정리된 최신 내용 받기
python3 scripts/journal.py                 # 오늘 페이지 만들기
python3 scripts/journal.py day 2026-11-21  # 특정 날짜 페이지 만들기
# ...기록 작성...
git add . && git commit -m "📖 2026-11-23 기록" && git push
```

## 6. 시간대 바꾸기

자동 생성 · 날짜 계산은 **LA 시간(America/Los_Angeles)** 기준입니다.
한국에서 기록한다면 [.github/workflows](../.github/workflows) 의 두 파일에서 `TZ: America/Los_Angeles` 를 `TZ: Asia/Seoul` 로,
`daily.yml` 의 `cron: "0 12 * * *"` 를 `cron: "0 20 * * *"` (한국 새벽 5시) 로 바꾸세요.
