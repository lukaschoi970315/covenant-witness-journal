# ☁️ 20명 함께 쓰기 — 무료 클라우드 연결 가이드

지금은 혼자 먼저 써보실 수 있도록 **개인 기기 모드**로 바로 동작합니다.
20명과 함께 각자 로그인해 비밀 노트를 쓰고 **관리자 점검**을 시작할 때, 아래 **3단계(약 5분)** 만 따라 하시면 됩니다. (완전 무료, 서버 관리 불필요)

---

## 1단계: 무료 Supabase 프로젝트 만들기 (2분)

1. [supabase.com](https://supabase.com) 에 접속해 **Start your project** → GitHub 계정으로 로그인합니다.
2. **New project** 를 누르고 이름(예: `3today`), 비밀번호를 입력한 뒤 지역(Region)을 가까운 곳(미국 서부 또는 서울)으로 골라 생성합니다.

## 2단계: 데이터베이스 만들기 (1분)

1. 왼쪽 메뉴에서 **SQL Editor** → **New query** 를 누릅니다.
2. 이 저장소의 [`supabase/schema.sql`](../supabase/schema.sql) 파일 내용을 **전체 복사해 붙여넣고 Run** 을 누릅니다. (`Success` 가 뜨면 완료)
3. *(권장)* 왼쪽 메뉴 **Authentication → Providers → Email** 에서 **Confirm email** 을 끄고 저장하면, 20명이 이메일 인증 링크 없이 가입 즉시 바로 기록할 수 있습니다.
4. 왼쪽 메뉴 **Authentication → URL Configuration** 에서 **Site URL** 을 아래 주소로 저장합니다:
   ```
   https://lukaschoi970315.github.io/covenant-witness-journal/
   ```

## 3단계: 웹사이트에 연결하기 (1분)

1. Supabase 왼쪽 메뉴 **Project Settings (⚙️) → API** (또는 **Data API / API Keys**) 에서 두 값을 복사합니다:
   - **Project URL** (`https://xxxx.supabase.co`)
   - **anon public key** (`eyJhbG...`)
2. 이 두 값을 채팅에 보내주시거나, [`config.js`](../config.js) 에 넣고 저장하면 끝입니다.

---

## 연결 직후 진행 순서

1. 웹사이트에 들어가 **가장 먼저 회원가입**을 하세요.
   → **첫 번째 가입자는 자동으로 관리자(Admin)** 가 됩니다.
2. 로그인 후 상단 **「관리자 점검」 → 「👥 멤버 · 초대코드 관리」** 에서 **초대 코드**(예: `3today2026`)와 **40일 집중 시작일**을 설정하세요.
3. 그동안 혼자 먼저 써두신 기록이 있다면 첫 화면 상단 배너의 **「내 클라우드 노트로 옮기기」** 버튼을 한 번 눌러 그대로 올리세요.
4. 이제 20명에게 **웹사이트 주소 + 초대 코드**를 알려주시면 됩니다!

> 🔒 **프라이버시 보장:** 데이터베이스(RLS) 수준에서 각 멤버는 **오직 본인의 노트만** 볼 수 있습니다. 다른 멤버의 글은 절대 조회되지 않으며, 원할 경우 각 날마다 `🔒 나만 보기` 를 체크해 관리자에게도 비공개로 둘 수 있습니다.
